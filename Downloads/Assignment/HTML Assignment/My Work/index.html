IT Web Programming 專案作品集

歡迎來到我的網頁前端練習專案，以下是各個網頁的功能導覽：

  • Exercise 1: Seminar on Web Programming
    使用 Table 呈現的 HKUSPACE 研討會資訊頁面。
  • Exercise 2: Math & Chemistry Formulas
    展示數學積分、雙曲函數（sinh z）與化學方程式的排版練習。
  • Exercise 3: CC's Library Resources List
    運用清單標籤（ul, ol）與不同符號樣式（羅馬數字、英文字母）製作的圖書館資源列表。
  • Exercise 5: Customer Bill Table
    複雜的表格（rowspan & colspan）切分練習，呈現客戶電話與 VoIP 帳單明細。
  • Main Project: Wikipedia Split Screen
    使用 Frameset 標籤將螢幕分割為三欄，同時載入多個電腦與科學主題的維基百科頁面。
